# DataX Labs – Task 1: Data Cleaning and Preprocessing

##  Task 1 Overview

This task was completed as part of the **Data Analyst Internship at DataX Labs**.

The objective of this task was to clean and preprocess a raw sales dataset using **Microsoft Excel Power Query** and prepare it for further analysis.

##  Dataset

The dataset was obtained from Kaggle:

**Restaurant Sales Data**
https://www.kaggle.com/datasets/rohitgrewal/restaurant-sales-data

The dataset contains restaurant sales information from a company operating across multiple cities. It includes information about sales transactions, customer demographics, and product details.

* **Rows:** 254
* **Columns:** 10
* **File format:** CSV

##  Tools Used

* Microsoft Excel
* Power Query

##  Data Cleaning and Preprocessing

The following steps were performed:

1. Loaded the CSV dataset into **Excel Power Query Editor**.
2. Checked column names and data types.
3. Changed the **Quantity** column to the **Whole Number** data type.
4. Checked for missing and empty values.
5. Checked for duplicate records; no duplicates were found.
6. Trimmed text values to remove unnecessary spaces.
7. Removed unnecessary spaces from the **Manager** column.
8. Standardized text by capitalizing each word.
9. Checked **Column Quality** to identify errors, null values, and empty values.
10. Validated the cleaned dataset.
11. Loaded the cleaned dataset back into Excel.
